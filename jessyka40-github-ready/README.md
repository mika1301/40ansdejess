# Jessyka — 40 ans 🎉

Site anniversaire prêt à publier sur **GitHub Pages** ou **Netlify**.

## Le site contient
- Compte à rebours jusqu'au **12 septembre 2026 à 19h15**
- Accès **Google Maps vers Le Domaine K** dès le haut de page
- Design bohème : sable, blanc, végétal, lumière chaleureuse
- Galerie avec photos de Jessyka et décorations bohèmes
- Ouverture des photos en grand
- Quiz « Qui connaît Jessyka ? »
- Livre d'or
- Suggestions musicales
- Affichage responsive sur téléphone

## Publier gratuitement avec GitHub Pages
1. Créer un nouveau dépôt sur GitHub, par exemple `jessyka40`.
2. Décompresser ce ZIP.
3. Envoyer **tout le contenu de ce dossier** dans le dépôt (notamment `index.html`, `style.css`, `script.js` et le dossier `photos`).
4. Dans GitHub : **Settings → Pages**.
5. Dans **Build and deployment**, choisir **Deploy from a branch**.
6. Choisir la branche `main` et le dossier `/ (root)`, puis **Save**.
7. Après quelques instants, GitHub donnera l'adresse publique du site.

## Publier avec Netlify
Décompresser le ZIP puis déposer le dossier qui contient directement `index.html` dans Netlify.

## Important
Le livre d'or et les suggestions musicales fonctionnent localement par défaut. Pour les partager entre tous les invités sur Internet, il faut connecter Supabase avec les clés prévues dans `script.js` et appliquer `supabase.sql`.
